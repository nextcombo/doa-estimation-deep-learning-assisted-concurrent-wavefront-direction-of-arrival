# [DOA Estimation] Deep Learning Assisted Concurrent Wavefront Direction of Arrival Estimation Based on FTMR Algorithm [with MATLAB Code]

Introduction 
Multipaths have hindered the implementation of the aforementioned subspace-based algorithms. Due to the reflection interference being merged into the direct component, the rank of the signal subspace is insufficient, making the preprocessing stage crucial for handling correlated received signals. For example, dimensionality reduction methods based on spatial smoothing (SS) technology [13]-[15] divide the entire antenna array into overlapping subarrays and then calculate the average output covariance matrix. Additionally, algorithms similar to ESPRIT [16] and its variants [17]-[19] have been used as alternatives to avoid the rank deficiency of SCM while maintaining computational simplicity.
In recent years, many researchers have introduced machine learning (ML) methods to address source localization problems [20]-[21]. Radial basis functions (RBF) [20] and Support Vector Regression (SVR) [21] are the first attempts to derive an inverse mapping from sensor outputs to arrival directions in space. Although these methods can be traced back to the 1990s, they are based on their simple structure and efficient computation, and they offer competitive performance against classical schemes. However, RBF and SVR rely on the distribution of training and test sets, and the size of training data points must be large enough to cover real-world scenarios. Moreover, their sensitivity to noise and outliers in the data leads to shallow model learning failures.
With the rapid development of machine learning, some deep architecture learning models have been designed to address DoA issues [22]-[26]. The dual-objective DoA classification multilayer perceptron (MLP) replaced the aforementioned ML models, but it required the same power assumption for input signals [22]. In [23] and [24], a deep multitask autoencoder-like MLP was proposed to overcome the obstacles posed by imperfect antenna arrays. However, the compression propagation of the filtering autoencoder in [23] unexpectedly changed the characteristics of the input features, making them only suitable for limited directions. The single deep neural network (DNN) in [24] only utilized fully connected (FC) layers that require a large number of learnable parameters. Inspired by the model proposed in [23], the framework in [25] eliminated the spatial filtering component and replaced the parallel multilayer classifier's MLP with a convolutional neural network (CNN). The residual networks in [26] consisted of parallel one-dimensional (1D) CNNs that directly regressed from the complex value virtual SCM outputs. Although their performance improved, the CNNs used in [25] and [26] required extensive computation.
In the aforementioned scheme, the ultimate goal is to approximate angles. However, in array processing algorithms based on subspaces, the number of source signals also plays a crucial role. For instance, for spectrum reconstruction based on DNN in [23]-[25], without the prediction of signal quantities, the highest peak representing the target direction cannot be separated from the undesirable peaks, especially under low SNR conditions. Particularly, for regression models, such as those in [20], [21], [26], this information essentially determines the size of the output layer and affects the overall result. In recent years, some advanced ITC methods have been introduced to enhance the performance of classic detectors, including the improved AIC (IAIC) in [27] and the linear shrinkage MDL (LSMDL) in [28]. Based on the distance between two consecutive feature values, gap-based detectors have also been proposed, such as the second-order statistical (SORTE) of feature values [29] and the ratio (ER) of feature values [30], to alleviate performance degradation in low SNR regions. Moreover, data-driven methods called Feature Value-Based Classification Network (ECNet) and Regression Network (ERNet) [12] have been proposed, outperforming other detectors even in highly polluted environments.
Almost all existing model-aided DOA estimation methods assume that the number of collision signals is known, without discussing which enumeration strategy is most suitable. By combining two different tasks, our goal is to build a complete deep learning (DL) architecture to improve the performance of dual targets in coherent scenarios, while still saving computational complexity.
In this paper, we propose a framework for dual classification DNN multi-DOA estimation in coherent multipath scenarios. Firstly, to decompose basic information from received signals, we adopt the full row Toeplitz matrix reconstruction (FTMR) scheme. Subsequently, we propose hierarchical processing, including feature value decomposition (EVD) applied to the output matrix of FTMR to complete feature signal feature extraction. Our contributions are summarized as follows:
Logarithmic Feature Value-based Classification Network (LogECNet) improves the collision signal detection capability by using the logarithm of feature values as input, compared to its previous data-driven multi-class classifiers [12]. The experimental results show that LogECNet outperforms classic detectors such as ECNet and AIC/MDL in terms of performance.
A model-assisted spectral-based direction finding method with adjustable angle resolution—Root Spectral Network (RSNet)—is proposed for estimating class MUSIC space spectrum (MSS). The Sigmoid activation function at the output of RSNet and binary cross-entropy loss function during training phase help in sharpening target DoA peaks, thereby enhancing the root mean square error (RMSE) performance relative to other spectral-based estimation schemes. Moreover, RSNet utilizes a set of polynomial coefficients, which leads to a reduction in overall complexity of our proposed approach.
The mathematical analysis of the FTMR algorithm is conducted to verify its robustness surpassing traditional forward/backward space smoothing (FBSS) plans in multipath scenarios. Specifically, the feature values decomposed from higher-order SCMs via FTMR are shown to have greater differences between signal and noise values. This characteristic not only enhances the detection capability of the FTMR algorithm on the same detection device as FBSS methods but also outperforms other configurations with subarray sizes. Finally, the computational complexity of the FTMR algorithm is derived to prove its suitability for large-scale antenna systems.

Conclusion
This paper proposes a signal number detection scheme based on LogECNet and a multi-DoA estimation method based on RSNet in coherent environments. LogECNet utilizes logarithmic feature values as input, enabling it to more accurately distinguish between the signal subspace and noise subspace. Compared to direct input of feature values, this improves the detection performance of the number of collision signals. Additionally, the FTMR algorithm is considered to overcome the rank deficiency of the signal subspace in multipath scenarios. Compared to the FBSS algorithm, the feature values produced by the output covariance matrix of FTMR are more reliable for signal counting, while significantly reducing computational complexity.
The proposed RSNet aims to estimate spatial spectra by employing multiple sub-networks. In the RSNet, the binary cross-entropy loss function during training phase sharpens the output spectrum compared to that generated by SFMC [23] and DeepMUSIC [25]. Furthermore, unlike existing data-driven methods, the coefficients of the polynomial equations in RMUSIC are obtained during the proposed feature engineering process, which not only helps reduce input size but also decreases the computational complexity of forward propagation.
Simulation results show that LogECNet using the FTMR algorithm outperforms LogECNet using the FBSS algorithm regardless of the size of the subarray. Compared with other spectral-based algorithms, the proposed RSNet algorithm exhibits better accuracy and complexity analysis indicates that the combination of FTMR and RSNet requires lower computational costs than other spectral DoA estimation schemes such as FTMR-SFMC, FTMR-DeepMUSIC, FTMR-SMUSIC, and Qian et al.'s HTMR scheme.
